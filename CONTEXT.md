# Марал Қыз ұзату — Состояние проекта

## Структура страницы (сверху вниз)

Каждый смысловой блок имеет своё фоновое изображение через CSS-класс `.visual-block`:

1. **Hero** — видео `hero.mp4`, заголовок Марал, дата 05.11.26
2. **InvitationText** — пригласительный текст (3 абзаца), длинный орнамент вверху, квадратный орнамент в центре
3. **TimeDetails** — «Той салтанаты»: две карточки (дата 05, время 17:00) + календарь + кнопка Google Calendar
4. **LocationCard** — адрес, «Aisha», длинный орнамент вверху/внизу, 2GIS-иконка
5. **Countdown + DressCode** — обратный отсчёт + дресс-код в одном визуальном блоке
6. **RSVPForm + Final** — анкета + «Құрметпен, той иелері: Дәурен - Римма»

## Цветовая схема (светлая тема, с сентября 2026)

Общий стиль: светлые айвори/кремовые панели поверх фоновых фото, тёмный сливовый текст, лавандовые акценты. Стеклянные (backdrop-blur) эффекты убраны ради перфоманса на старых iPhone. Хиро с видео — единственный тёмный блок с белым текстом.

- `--ivory`: #faf6f0 — фон панелей (.ivory-card, .rsvp-card)
- `--cream`: #f6efe7 — фон страницы/оболочки
- `--linen`: #e9dfd2 — плейсхолдер за фото (.visual-block)
- `--plum`: #4a244f — основной текст
- `--lavender-soft`: #c8add4 — светлые акценты (на тёмном хиро)
- `--lavender`: #9f74b4 — фиолетовый
- `--lavender-deep`: #7b2cbf — орнаменты, кнопки, акценты на светлом
- Tailwind-цвета заданы через RGB-триплеты (--plum-rgb и т.д.) с <alpha-value> — модификаторы вида text-plum/60 работают

## Круглые орнаменты

Один вращающийся орнамент на стыке Hero и InvitationText:
- `RotatingOrnament` — позиция `-right-[92px] top-[86svh]`, размер 185px
- Вращается 30 сек, цвет глубокого фиолетового

## Важные детали

- Время: **17:00** (в .ics, в countdown, в данных)
- Кнопка календаря: скачивание .ics (нативно на iOS/Android) + запасная ссылка Google Calendar
- 2GIS иконка: `2gis-icon-logo.svg` — цветной логотип на светлой кнопке
- Открытка: створки раздвигаются при открытии (framer-motion), светлая айвори
- Аудиоплеер: компактный, светлый, кнопка play — глубокий фиолет
- Шрифт заголовка: Playfair Display
- Секции: контент в светлых панелях (.ivory-card), фото видны между блоками
- Открытка и модалки безопасны в ландшафтной ориентации (скролл)
