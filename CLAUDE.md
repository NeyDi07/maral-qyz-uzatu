# Марал Қыз Ұзату — Контекст Проекта

## Что это за проект
Сайт-приглашение на Қыз ұзату (сторона невесты, казахская традиция). Mobile-first лендинг с музыкой, scroll-анимациями, анкетой RSVP и отправкой ответов в Google Sheets.

## Стек
- Next.js 16.3 App Router + TypeScript
- Tailwind CSS
- Framer Motion
- Vitest + Testing Library
- Vercel deployment
- Google Apps Script Web App для сбора ответов

## Ключевые решения (чтобы следующий ИИ не перестраивал)

### Общий визуальный стиль
- С 23.09.2026 утверждена СВЕТЛАЯ тема по запросу клиента (прежняя тёмная «фотоцентричная» схема ушла): светлые айвори/кремовые панели поверх фото, тёмный сливовый текст, лавандово-золотые акценты.
- Хиро с видео остаётся тёмным с белой типографикой — единственный кинематографичный блок.
- Стеклянные backdrop-blur эффекты убраны (перфоманс на старых iPhone + просьба клиента).

### Стартовый экран
- Пользователь заходит — видит только открытку с фото Марал, именем, `Қыз ұзату`, кнопкой `Шақыруды ашу` и текстом `Басыңыз`.
- После нажатия музыка запускается с 30-й секунды (main.mp3), плеер появляется сверху, страница скроллится.
- Hero не имеет кнопки открытия (она только на стартовой открытке). Hero — чистое фото + имя + дата + ою.

### Музыка и плеер
- 3 трека (main.mp3, balausa.mp3, qyz-uzatu.mp3).
- Переключение между треками — кнопки в плеере.
- Плеер фиксирован сверху, минималистичный: тонкий progress bar + кнопки назад/play-pause/вперёд.
- Без названия песни и хронометража, чтобы не занимать много места.
- Без лишних анимаций (hover без перепрыгиваний, ползунок без сложного градиента).

### Анимации
- Сделаны через Framer Motion ScrollSection.
- Ограничить количество: не перебарщивать с эффектами. Оптимальное количество, стильно, не отвлекает.
- Без дергания фото на hero (убрана pan-анимация).
- Секции: opacity/transform reveal при скролле.
- Поддержка prefers-reduced-motion.

### Анкета RSVP
- Есіміңіз (обязательное поле)
- Три варианта: Әрине, келемін / Жұбайыммен бірге келемін / Өкінішке орай, келе алмаймын
- Если "Жұбайыммен бірге келемін" — появляется поле Жұбайыңыздың есімі.
- Если "келе алмаймын" — появляется мягкий reconsideration-блок с кнопками "Жарайды, келемін" и "Иә, өкінішке орай келе алмаймын".
- Отправка через Google Apps Script endpoint в Google Sheets.
- Переменная: NEXT_PUBLIC_RSVP_ENDPOINT.
- Колонки в таблице: Submitted At | Name | Attendance | Partner Name | User Agent.
